# 测试与质量规范

本文是验收门禁，不是设施或通过状态清单。实际命令、测试发现范围、依赖与 CI 从根及受影响包配置读取，不在文档重复工程现状。接口断言来自 [OpenAPI](../contracts/openapi.yaml)和 [API 设计规范](API设计规范.md)，视觉/字体来自 [响应式规范](响应式与页面结构规范.md)，产品/隐私来自 [PRD](戒网瘾机构公共监督平台-PRD.md)。

## 1. 安全、可重复的环境

- 所有单元/组件/契约/集成/浏览器/预览只用完全虚构数据与保留域名；不用真实机构、人物、投稿、生产数据库/日志、邮件、Issue 或其脱敏派生物。
- 固定依赖锁、运行时/浏览器版本、时区、locale、seed、clock 和字体；安装使用已有 lockfile 的冻结模式，不因检查缺失擅自安装新工具。
- 每例隔离 provider、cache、handler、角色与存储；结束关闭 app/连接、恢复时钟并清理测试状态。测试库按 run/worker 隔离，任何 DROP/TRUNCATE 前验证一次性测试标记与目标，禁止连接生产或共享 staging。
- 默认拒绝真实出站网络，浏览器只允许本次本地 Web/API 与显式拦截的合成来源；外部身份、验证码、邮件、GitHub、AI 在边界 stub。被验收的 SQL、投影、权限和状态规则不能 stub。
- Mock/测试身份/场景入口不进生产；Real 失败不回退 fixture。合成隐私探针单独运行，默认关闭 trace/HAR/video/自动失败截图，不把请求正文放到报告。

## 2. 按变更选择门禁

| 改动                  | 必须验证                                                                           |
| --------------------- | ---------------------------------------------------------------------------------- |
| 仅文档                | 授权范围、链接/引用、规则冲突、命令真实性、敏感信息                                |
| 手写代码              | 受影响包 lint/format、typecheck、行为测试与 build                                  |
| UI/交互/样式          | 组件/状态画廊、核心 Mock E2E、规定宽度、长文本/字体、键盘/焦点、axe 与必要视觉回归 |
| API/DTO/Adapter/Mock  | 契约、examples/响应、生成类型漂移、兼容性、全部适用错误与公开投影                  |
| 后端/权限/状态/数据库 | 真实路由与隔离数据库 integration、迁移/事务、允许/拒绝权限格、日志与不可见性       |
| 跨层写入/发布/撤回    | Real integration E2E；私有队列、发布可见、隐藏/撤回后不可见及缓存失效              |
| 合并/发布             | 全部适用 CI、源码与最终产物/报告的隐私/secret 扫描、依赖风险及人工 review          |

先确认脚本真的存在且发现测试。缺失、失败、取消、超时、零用例和 `ui-only` 不能记通过；不以 root 汇总命令或一次重跑替代遗漏门禁。不关闭规则、降低覆盖率、删用例或用 `continue-on-error` 获绿灯。

## 3. 测试分层与行为

- **单元**证明纯函数、参数/日期、排序、投影、安全错误及状态允许/拒绝分支。
- **组件/ViewModel**证明交互、异步状态、URL/cache、表单与焦点语义，不证明真实 CSS 布局或服务端权限。
- **状态画廊**展示适用 default/hover/focus/disabled/loading/error/empty/mobile/long-text/reduced-motion/permission/privacy；有交互须实际运行断言，静态 build 不等于测试。
- **契约**同时验证 OpenAPI examples、Mock 和真实 HTTP 响应，类型通过不等于运行时合法。
- **集成**经过真实路由、中间件、投影、事务与隔离数据库；内存 repository 测试不冒充 PostgreSQL/迁移验收。
- **E2E**聚焦跨页面用户任务，Mock 与 Real suite 分开报告。必要视觉回归只取稳定关键区域，避免无限快照。

用 role/label/可访问名称定位，优先测试可观察行为，不测组件内部 state 或第三方 DOM。异步操作 await，等待可观察条件/deferred gate/受控时钟；禁止硬编码 sleep/`waitForTimeout`、深层 CSS/XPath、用 `networkidle` 冒充任务完成，或在重试断言内重复提交。

手写源码覆盖率最低 lines/functions/statements 80%、branches 75%；权限、状态、公开投影、脱敏、URL 安全与错误映射四项均至少 90%，每条安全允许/拒绝规则另有具名用例。只排除生成类型、声明、测试与静态素材；低层覆盖不替代核心 E2E，聚合覆盖率不掩盖安全拒绝分支。

## 4. 必测边界

- 查询：正常/别名/空、筛选组合、排序平局、边界分页、超页、非法/重复/未知参数、日期未知/区间、null 与空数组；URL 分享、刷新及回退一致，旧请求不覆盖新查询。
- 异步：加载、慢、取消、断网、timeout、各契约 HTTP 错误、非 JSON/畸形响应、未知枚举、额外私有字段、版本不匹配。响应校验错误不当空结果，不推断已核验/已发布。
- 公共可见性：草稿/隐藏/撤回与不存在一致；父对象不可见后子资源及相关 cache/计数/metadata 不泄露，旧 ETag/304 不复活。详情成功后子接口 404、后台撤回与浏览器返回均覆盖。
- 分页关联：超过一页的时间线/来源仍可访问；来源引用能定位对应公开内容，不假设引用一定在第一页。
- 状态与权限：未知角色拒绝，身份/签名/issuer/audience 失效、每角色每动作/资源允许与拒绝、登出清私有 cache；Researcher 不发布、Reviewer 不代替 Publisher、缺检查/理由/复核拒绝，版本冲突不覆盖或重放。
- 写入：本地/服务端错误、pending 防双击、超限/未知字段/危险链接/HTML/multipart、反滥用/幂等、未确认与成功仅安全引用；正文只在本人当前表单短期保留，不进 URL/存储/错误摘要/成功页。
- 事务：状态、公开投影和 audit 任一失败全部回滚；发布/隐藏/撤回理由受限存储。规划功能缺契约/实现时标阻塞，不用 stub 成功计入通过率。
- 后期渠道/AI/文件只在对应能力获准启用前测验签、重放、隔离、工具白名单/schema/超时及 fail-closed；不触发真实外部消息或生产发布，自动化仍默认关闭。

## 5. 契约验证

使用支持 OpenAPI 3.1/JSON Schema 2020-12 的工具；受控本地 refs，CI 不拉任意外链。请求参数必要解析与响应验证分开，响应关闭 coercion、默认填充及移除额外属性。

每个交付 operation 的路径、方法、参数、成功/空/所有错误状态、header、content-type 与嵌套白名单须有实际响应验证；逐操作报告缺失路由，不能只验证两个样例。注入新增私有字段、超长文本、错误 key、重复数组项/字典项、无效日期与带凭据 URL 必须拒绝。跨字段日期/来源最低要求、关系可见性、计数/metadata 完整性另测语义条件。

生成文件与同版本契约一致；与发布基线比较破坏性，未经批准版本/兼容方案不得通过。前后端、Mock 与报告记录同一契约版本，不手工同步多份 DTO。

## 6. 响应式、字体与无障碍

按响应式规范的五个宽度检查适用成功/加载/空/错/不可见状态；覆盖抽屉、弹层、长文本、permission/privacy、reduced-motion、软键盘、200% 文字放大、320px 回流与用户文字间距覆盖。检查实际字号下限、内容/焦点未遮挡、无页面横向滚动和核心任务可操作。

自动 axe 选定 WCAG 2.2 AA 规则 violations 为零，incomplete 人工处理；不全局禁用规则。再人工验证 Tab/Shift+Tab、Esc、跳转正文、路由标题/焦点、错误关联与读屏状态；上线前用 NVDA/VoiceOver 等完成公共和管理任务。对比度、目标尺寸和颜色之外的状态含义不能靠像素测试证明。

视觉基线固定环境、字体、数据、时间与主题；等待字体和业务完成，不隐藏错误/焦点。只覆盖高价值区域；建议像素差比例不超过 0.002，差异仍须人工审阅，不能 mask 来源/证据/错误/权限/安全文案或在 CI 自动接受新基线。

## 7. 隐私、secret 与最终产物

- 公开 DTO 逐字段/递归白名单，加私有字段与唯一合成探针；响应、计数、DOM/meta、URL/存储、cache、日志/遥测、source map 与截图/报告均不得出现禁止数据。文字规则与结构化规则分别检测，不只搜 `email` 字符串。
- 任意客户端 header/未知参数名/错误 URL 也可能携带敏感信息；测试这些值不进入日志和安全错误。错误报告只给 operation、status、字段/schema 路径、规则与数量，不打印原始数据。
- 扫描源码、最终发布包和拟上传报告；检查 `.env`、密钥、连接串、个人路径/身份、私有信息、备份、Mock fixture/测试账号、压缩包和 source map。生产 source map 默认不公开，私有上传仍先扫描。
- scanner 要有合成正/负例自检；缺工具、异常、路径不存在、零文件或跳过附件不是零命中。例外只限精确假阳性，有 owner、理由与期限，不能忽略整目录或真实 secret。
- 图像/视频另查元数据及人工审阅；扫描通过才上传，拟发布包必须是被测试/扫描的同一份。合成探针专项默认不保留原始附件；安全摘要建议 30 天，经扫描受限失败附件最多 7 天。
- 依赖/镜像高危与严重漏洞修复或经精确有效专项评审；fork/不可信 PR 不注入生产凭据，不用带写权限的流程执行未审代码。

## 8. 完成与失败处理

失败先给用例 ID、版本、场景/宽度、预期/实际及安全化证据。诊断重跑保留首次失败；flaky 记录 owner/期限，安全/隐私/人工终审/核心闭环不能跳过或隔离后假通过。权限绕过、真实数据、公开草稿、撤回复活和 secret 立即阻断。

交付分别写“通过 / 失败 / 未执行 / 阻塞”，报告实际命令、结果、范围、缺口和人工 review；建议命令、文档清单、Mock 成功或 AI 自评不是实际验证。不把代码测试代替事实/法律/隐私终审，也不把文档检查当应用 CI 或生产发布许可。
