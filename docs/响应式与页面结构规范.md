# 响应式与页面结构规范

适用于公共端、管理端及组件预览。本文规定验收要求，不描述工程现状；产品/隐私边界见 [PRD](戒网瘾机构公共监督平台-PRD.md)，接口见 [OpenAPI](../contracts/openapi.yaml)，测试流程见 [测试与质量规范](测试与质量规范.md)。颜色、字体族、间距等实现值读取已批准的 tokens，设计参考图不能覆盖规格。

## 1. 布局与回流

移动优先。390、768、1024、1280、1440px 是必测宽度，不是固定设备分类；基础样式还须适应 320 CSS px 回流、横屏、软键盘及文字放大，不能设置 `min-width: 390px`。

| 宽度   | 布局基线                                                        |
| ------ | --------------------------------------------------------------- |
| 390px  | 单列、16px 页面边距；导航折叠，筛选使用底部抽屉或全屏面板       |
| 768px  | 24px 页面边距；正文与时间线优先单列，辅助区可两列；筛选保持面板 |
| 1024px | 32px 页面边距；可采用 12 列网格、左筛选轨和主内容/证据侧栏      |
| 1280px | 边距至少 32px，内容最大宽度 1200～1280px并居中                  |
| 1440px | 沿用最大宽度，增加留白，不无限拉长正文或拉远操作                |

- 栅格和 flex 子项可收缩；长名称、多别名、无空格文本、长链接和错误说明能换行，不撑破容器。不以省略号隐藏唯一来源信息。
- 正文行长受控；中文长文建议每行约 30～40 个汉字，英文约 60～75 个字符，以实际阅读和缩放验收为准。
- 先换行、改单列、调整间距或信息分组，不能通过缩小字体塞内容；来源、日期、回应、限制说明和安全入口不得因窄屏消失。
- 页面本身不得横向滚动。必要的二维数据表可局部滚动，须有名称、滚动提示和键盘操作；手机核心任务不能依赖横向寻找唯一安全操作。
- 隐藏的桌面/移动控件退出可访问树和 Tab 顺序；sticky 区域不得遮挡标题、焦点、错误或弹层。布局不能复制两份业务内容或改变阅读顺序。

## 2. 字体不能太小

以下是项目默认浏览器设置、100% 缩放下的最低排版门槛，**不是 WCAG 规定的统一最小字号**。使用语义字号 token、`rem` 和无单位行高；保留用户字体与缩放设置，不通过缩小根字号、`transform: scale()` 或禁用缩放绕过门槛。

| 用途                                    | 最低字号                           | 行高                           |
| --------------------------------------- | ---------------------------------- | ------------------------------ |
| 正文、资料摘要、政策与阅读内容          | 16px（通常为 1rem）；长文优先 18px | 1.5～1.8，中文默认建议 1.6     |
| 输入、按钮、导航、表单标签              | 16px                               | 1.25～1.5；容器随换行/放大增高 |
| 证据状态、安全/隐私提示、错误与确认信息 | 16px，不按“辅助信息”降级           | 1.5～1.8                       |
| 时间、非关键元数据与辅助说明            | 14px（通常为 0.875rem），优先 16px | 1.5～1.7                       |
| 编号、代码、命令与技术展示              | 14px；连续阅读优先 16px            | 1.5～1.7                       |

- 不出现低于 14px 的产品文字；小屏不降低上述下限。标题至少与正文形成清晰层级，允许响应式调整，但不得裁切或遮挡。
- 不使用过细字重、低对比度或过密字距制造“精致感”。普通文字对比度至少 4.5:1；达到 WCAG 大字定义的文字至少 3:1。辅助文字也适用，字号大不能替代对比度检查。
- 文字可放大至 200%，中间缩放比例也不得丢失内容或功能；检查按钮、标签、表格、弹层和字段错误，不仅检查正文。不用固定高度配合 `overflow: hidden` 裁掉文字。
- 按 WCAG 1.4.12 覆盖为行高 1.5、段后间距 2em、字距 0.12em、词距 0.16em 时，内容和功能仍完整。这是用户覆盖测试，不要求默认样式全部使用这些值；无词间空格的中文按语言适用性检查。
- 字体本地提供或使用本地 fallback，避免第三方字体请求；跨字体、中文/拉丁混排、最长合法内容均需验收。

依据：[GOV.UK 字体可访问性改进](https://designnotes.blog.gov.uk/2022/12/12/making-the-gov-uk-frontend-typography-scale-more-accessible/)建议避免低于 16px 且不因小屏缩小正文；Guardian 仅为非关键辅助信息保留 14px 底线。可访问性要求见 [WCAG 1.4.4 放大](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)、[1.4.10 回流](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)、[1.4.12 文字间距](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)和 [1.4.3 对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

## 3. 页面结构与交互

- 每页唯一 `main`、明确页面标题及通常一个 `h1`；标题层级连续，导航有不同的可访问名称，提供可见焦点的“跳转到正文”。链接用于导航，按钮用于操作。
- SPA 路由变化更新页面标题并采用一致的焦点/公告策略；列表刷新不强行移走用户焦点。URL 保存可分享的搜索、筛选、排序和分页，刷新及前进/后退可恢复。
- 首页以产品定位、搜索、名录/来源入口、资料范围与更新时间为主任务；不使用曝光排行、危险分数、虚假 KPI 或煽动性图像。
- 名录保留身份、粗粒度地区、证据状态、来源数和复核日期。无结果只说明“没有匹配的公开档案”，不暗示没有风险。移动筛选草案仅在“应用”后写入 URL；取消不修改已应用条件。
- 详情按身份核对、证据图例、时间线、来源、机构回应、更正/隐私入口与资料限制组织。移动侧栏转入正文，来源不能成为侧栏唯一信息；事件/报道/复核日期明确区分，每条事件能回到来源。
- 来源行保留标题、发布者、日期、证据和链接状态。外链标注离站/新窗口；保持 `noopener`，按隐私策略使用 `noreferrer`。视频不自动播放、下载、重托管或嵌入第三方追踪。
- 表单先说明安全边界，字段单列、标签与错误关联；联系方式选填，P0 不出现上传/附件占位。失败不复制敏感正文到提示，提交成功只在服务端确认后显示安全引用；Mock 明示模拟。
- 政策页提供短摘要、目录与细节；核心安全提示不能全部藏在折叠区。管理页移动顺序为内容、证据/差异、审核清单、操作；发布/隐藏/撤回分别命名，明确理由、后果和取消，确认框不能授权。

## 4. 状态与无障碍

- 覆盖加载、更新、成功、空、网络/超时错误、来源失效、不可见、401/403及未知响应等适用状态；错误不显示堆栈、SQL、内部路径、身份或提交正文。
- 隐藏/撤回只显示契约允许的通用不可用信息，立即撤出旧正文及相关缓存；不从公共 404 猜测私有状态、展示内部原因或静默改用 Mock。
- 证据、风险与成功/错误状态同时有文字，颜色不是唯一载体；红色只用于安全紧急提示与危险操作，不能暗示司法结论。
- 所有控件有名称，表单有 label、描述和错误关联；提交校验失败聚焦错误摘要或首个错误。通知适度使用 live region，Toast 不是唯一重要反馈。
- Dialog/Drawer 保留标题、焦点约束、Esc、关闭入口与焦点恢复；Tabs、菜单等可键盘操作，不只支持 hover/点击。不要以 `div onClick` 替代原语或删除 ARIA 行为。
- WCAG 2.2 AA 目标尺寸至少满足 24×24 CSS px 或条款间距例外；主要操作建议 44×44px。控件与焦点指示满足适用的 3:1 非文本对比度，不删除 outline。
- 无自动轮播、滚动劫持、强制视差或闪烁敏感提示；过渡约 150～220ms 且不妨碍立即阅读。`prefers-reduced-motion` 下移除非必要动画。
- 图像只作非识别性参考，正文/状态由语义 HTML 渲染；装饰图空 `alt`，信息图有文本替代，素材权利与人工批准明确。

## 5. 验收

使用完全虚构数据，按五个规定宽度检查关键页面的成功/加载/空/错误与相应不可见状态；再检查长文本、200% 放大、320px 回流、文字间距覆盖、软键盘、键盘/读屏与 reduced-motion。实际计算字号不得低于第 2 节门槛；截图“看起来可读”不能替代字号、对比度、焦点与内容完整性检查。

自动 a11y/视觉检查与人工键盘、屏幕阅读器检查共同完成；组件库默认行为不等于 Guardian 已通过验收。
